# リンバス宝箱チェッカー（HTML版）使い方ガイド

スマホやPCのブラウザだけで動く、ログインや通信不要のオフラインツールです。
`treasure_checker.html` をブラウザで開くだけで使えます。データは端末のブラウザ内（localStorage）に保存されます。

---

## できること

- キャラクターごとに「テメナス」「アポリオン」2つの宝箱イベントの進行状況を管理
- 開けた箱が外れだった場合、外れ確定の箱を記録して次の候補を絞り込み
- 週5回までの挑戦回数の管理
- コード（テメナスコード／アポリオンコード）を使った追加抽選の管理
- 当たり・外れの履歴を日付つきで記録
- 日本時間（JST）の毎週月曜0:00に自動で週リセット
- 前週5回使い切って当たりが出なかった場合、外れ確定の箱情報を自動で翌週に引き継ぎ

---

## 画面の流れ

### 1. キャラクター一覧画面

最初に表示される画面です。

- 右上の「＋ キャラ追加」から新しいキャラクターを登録します
- 登録時にキャラクター名と種族（アイコン）を選びます
- 一覧の各キャラクターには、テメナス／アポリオンそれぞれの「残り回数」「候補箱数」が表示されます
- キャラクターをタップするとチェッカー画面に進みます
- 「編集」「削除」ボタンで登録情報の変更・削除ができます（削除は確認ダイアログあり）

### 2. チェッカー画面

メインの操作画面です。

| 要素 | 説明 |
|---|---|
| 上部タブ（テメナス／アポリオン） | どちらのイベントを操作するか切り替えます |
| 残り回数バッジ | 今週まだ挑戦できる回数（最大5回） |
| 前週引継ぎバナー | 前週の外れ情報を引き継いでいるときに表示 |
| コードバナー | テメナスコード／アポリオンコードの使用状況。「コードを使う」ボタンでコードモードに切り替え可能 |
| 箱一覧 | 開けたい箱をタップして選択します。外れ確定の箱は薄く表示され選択できません |
| ✓当たり！／✗外れ ボタン | 選んだ箱の結果を記録します |
| アドバイス欄 | 今の状況に応じたヒント（候補が1つに絞れたときは「必ずここ！」と表示） |
| 結果履歴 | これまでの記録を新しい順に表示（日付・回数・箱・結果） |
| 週リセットボタン | 手動で週の状態をリセットしたいときに使用 |

#### 箱を選んで記録する手順

1. 開けたい箱をタップして選択（枠が青くハイライト）
2. 実際にゲーム内で箱を開けた結果に応じて「✓当たり！」または「✗外れ」をタップ
3. 当たりの場合 → その週の全箱が再び候補に戻ります
4. 外れの場合 → その箱は「外れ確定」になり、次回以降は選択できなくなります
5. 候補が1箱だけになると、その箱が当たり確定として案内されます

#### コードを使う場合

1. コードバナーの「コードを使う」をタップ（コードモードに入ります）
2. 開けたい箱を選択し、当たり／外れを記録
3. コード使用分も通常の残り回数から1回消費されます（アプリ内仕様と同じ）
4. 一度使うと「使用済み」になり、その週は再利用できません

## 週リセットの仕組み

- 毎週**月曜0:00（日本時間・JST）**を境に、自動的に新しい週として扱われます
- 端末のタイムゾーン設定に関わらず、常にJST基準で判定されるため、海外で使っても挙動は変わりません
- 自動リセット時：
  - 前週に5回すべて使い切ったのに当たりが出なかった場合 → 外れ確定だった箱の情報を**そのまま引き継いで**新しい週を開始（チェッカー画面に引継ぎバナーが表示されます）
  - それ以外の場合 → 全箱が候補の状態でリセット
- 結果履歴（日付つきの記録一覧）は、週が切り替わる・手動リセットするたびにクリアされます（箱の当たり外れ情報とは別管理）

### 手動リセット

チェッカー画面下部の「↺ 週リセット」ボタンから、好きなタイミングで手動リセットも可能です。

- 外れ確定の箱がある場合、「引き継いでリセット」「引き継がずにリセット」を選べます
- 残り回数は5回に戻り、結果履歴はクリアされます

---

## データの保存について

- すべてのデータはこの端末のブラウザ（localStorage）にのみ保存されます
- 他の端末やブラウザとは同期されません
- ブラウザのキャッシュ・閲覧データを消去すると記録も消えるのでご注意ください
- サーバーには一切送信されないため、オフラインでも利用できます

---

## 注意事項

- 候補が1箱しかない状態では「✗外れ」ボタンは押せません（当たりが確定しているため）
- 4箱すべてが外れ確定になることは通常発生しません（最後の1箱は必ず当たりのため）が、万一そうなった場合は安全のため全箱が再び候補に戻ります
